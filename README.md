# Squished

A Unity game created for the October jame gam game jam:

##  Engine & Building Locally

Engine: Unity
How to Run/Build:
  1. Clone this repository to your local machine:
     ```bash
     git clone [https://github.com/jyasda/Squished.git](https://github.com/jyasda/Squished.git)
     ```
  2. Open Unity Hub
  3. Click Add > Add project from disk
  4. Select the cloned Squished project folder.
  5. Open the project in Unity and launch the Main Menu scene from Assets/Scenes/.

How to Play
Controls:
Use WASD or the arrow keys to move around

Win condition: There is no end to the game but try to dodge the flyswatters for as long as you can.

Objective: Try to beat your highest score by dodgeing the flyswatters
